## Decisions Made
- **M3 redesign scope is the whole app, not just admin** — corrected from prior sessions' admin-only framing. Sequencing: admin first, then client-facing. Recorded to memory (`project_m3_redesign_scope.md`) so this doesn't drift back to admin-only framing in a future session.
- **Never start a dev server (`npm run dev`) under any circumstance** — hard rule going forward, recorded to memory (`feedback_no_dev_server.md`). Verification stops at one-shot commands (`lint`, `build`, `tsc --noEmit`, `vitest run`). If something can only be confirmed by loading a page, say so explicitly and let the user check.
- **Dashboard stat-card tones intentionally bypass tenant customization** (raw `--md-*-container` vars, not `bg-primary`/`bg-accent`/etc) because those semantic tokens were found to collapse to the same color once a tenant customizes their primary brand color — documented as a deliberate, accepted tradeoff in `src/components/AGENTS.md`, not a bug to "fix" later.
- **Appointment/event-block color treatment for Stage 3 will change from solid-80%-alpha-fill+white-text to soft-tonal-tint+dark-text+left-accent-border** — not just cosmetic: the old approach could produce illegible white-on-light-pastel text if an admin picks a light custom master color; the new approach is robust to any admin-picked hex, matching the design system's own pattern.
- **True edge-to-edge full-viewport width for the calendar page is explicitly out of scope for Stage 3** — the shared `admin/layout.tsx`'s `max-w-5xl` wrapper is the single source for every `/admin/*` page's content width; escaping it structurally requires moving that wrapper into each page individually, a bigger change than "restyle the calendar," and needs its own explicit user decision rather than being bundled in.
- **`availableSlotColor`/`dayOffColor` must stay literal hex strings, never CSS `var(...)` references** — every consumer does `color + '40'`-style string concatenation for alpha, which silently produces invalid, non-rendering CSS if given a `var()` string instead of hex. Caught during Stage 3 planning specifically because of heightened scrutiny after the Stage 2 regression.
