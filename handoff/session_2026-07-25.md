## Decisions Made

- **Real client review collection (submission, moderation) is a separate future project**, not part of this feature — flagged as out-of-scope-creep risk during brainstorming and kept out all session.
- **Hybrid content model**: fixed registry of 3 block types (`photoWidget`/`photoGallery`/`text`), not a freeform block-builder — admin/master compose pages from this fixed set rather than an open-ended canvas.
- **Reorder is real drag-and-drop (`@dnd-kit/*`), not buttons** — explicit reversal by the user of an earlier "ship buttons first, add DnD later if needed" agreement, after seeing the buttons live. New dependency was pre-authorized for this specific purpose.
- **No privileged default language anywhere in this feature** — `Page.title_pl` and block `text_pl` are nullable; validation requires *any* currently-enabled locale to be filled, never Polish specifically. This required a real SQLite table-rebuild migration (`ALTER COLUMN` isn't supported), explicitly pre-approved as expected/safe for the `Page` table only.
- **One entry point per admin row** (edit sheet → "Manage blocks →" link) instead of two separate icons — confirmed UX after the two-icon version confused the user badly live.
- **Shared `Sheet` component's slide animation widened app-wide** (all 4 sides, full off-screen travel) — a deliberate shared-component change, sanity-checked against all 7 existing Sheet consumers before shipping.
- **Dead code deleted outright, not orphaned-and-flagged**: `ReviewsMarquee.tsx`/`src/lib/reviews.ts` removed the moment their last usage was replaced, per explicit "no point keeping known-dead code" instruction.
- **`npm run build` during agent verification can corrupt a concurrently-running `next dev` session's routing** — discovered and documented this session; the practical mitigation adopted was verifying live changes via direct `curl` against the running server rather than asking the user to screenshot after every micro-adjustment, once this became a recurring source of "nothing changed" false alarms.
