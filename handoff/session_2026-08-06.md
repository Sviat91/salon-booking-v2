## Decisions Made

- **Save-button "just-saved" indicator persists until the next edit, not on a timer** — mirrors `SettingsForm.tsx`'s existing pattern (`state.success` message with no auto-dismiss), avoids inventing a new UX convention.
- **Photo/block-save flicker fix is optimistic local state, not waiting on `router.refresh()`** — same reasoning as the pre-existing `handleReorder` function; the visible UI should never depend on a network round-trip when the outcome is already known client-side.
- **OG image is one shared site-wide image (not per-master/per-page)** — this is a single-tenant-per-deployment app, so one image covers homepage/master pages/custom pages via the root `opengraph-image.tsx` file convention and Next's metadata inheritance.
- **`sharp` import in `og-image.ts` is lazy and wrapped in try/catch, never top-level** — this module's exports are imported by Next during metadata resolution for *every* page; a module-scope throw would break the whole site's `<head>`, not just the preview card.
- **Header controls (Back/Language/Theme) live in real in-flow content, never `fixed`/`absolute` overlays** — the entire class of "controls overlap page content" bugs stemmed from independently-positioned overlays with guessed clearance padding that never matched their actual rendered size; real layout flow makes the bug structurally impossible rather than tuning the guess.
- **Burger menu for custom-page navigation is mobile-only (`lg:hidden`), never replaces the desktop tab strip** — initially implemented as an unconditional replacement at every breakpoint (a scoping mistake, corrected after user feedback); the "unbounded page count doesn't fit next to other controls" justification only holds on narrow viewports.
- **`leadingSpaceClassName` (logo-clearance reserved space) is real layout padding only on the `lg:`-and-up desktop tab strip** — never applied to the mobile burger/Back container (that padding assumed *scrollable* content that could safely extend past it; Back/burger must always stay visible/clickable, so the same padding there just crowds everything into a mobile corner instead).
- **Never re-run `npm run dev`/`npm run build` locally** — all production-build-only type errors this session were discovered via the user's actual VPS Docker build log and fixed by reasoning through the code + `npx tsc --noEmit` (read-only, safe), never by attempting a local build.
