## Decisions Made

### Design System Architecture
- **M3 (Material Design 3) warm-rose** palette as the visual foundation. Primary: `#8B4A58`, surface: `#FFF8F6`, primary container: `#FFD9DC`
- **Font: Roboto** (300/400/500/700) via `next/font/google` — replaces Inter. GDPR-safe (self-hosted by Next.js)
- **Two-layer CSS variable chain**: DB injection (`--color-*`) → M3 fallback (`--md-*`). This keeps full admin customisation while M3 serves as the default palette
- **`--color-*` CSS defaults in `m3-tokens.css`**: provides M3 values even before DB injection (SSR, edge, fresh deploys)
- **DEFAULT_CONFIG in tenant.ts** updated to M3 — fresh deploys auto-get M3 palette without needing Reset click
- **Reset to M3 defaults**: key-based remount (not controlled inputs) — clean, avoids refactoring ColorRow to controlled
- **`--radius: 0.75rem`** (12px, M3 medium) — cards/panels. Buttons use `rounded-full` (pill). Inputs use `rounded-[--radius]`

### Naming clarification (confusing DB field names)
| DB field | CSS var | Admin label | Semantic role |
|---|---|---|---|
| `primaryColor` | `--color-primary` | "Secondary Tint" | Hover/accent backgrounds |
| `secondaryColor` | `--color-secondary` | (BackgroundSection) | Main page background (solid) |
| `accentColor` | `--color-accent` | "Primary Button" | Primary action color |
| `cardColor` | `--color-card` | "Card Background" | Card/panel bg |
