## Decisions Made

- **E.164 phone comparison** (not last-9-digits) — closes the cross-country suffix vulnerability without regressing pre-existing un-migrated phone rows.
- **`$transaction` over a DB unique constraint** for the double-booking race — the conflict check is an overlapping-range query, not an exact-slot match.
- **CSP with `unsafe-inline`, not nonce-based**, made dev-mode-aware after it broke local dev hydration.
- **`git rm --cached` only, no history rewrite** for the leaked `app.db`/`uploads`.
- **`canModifyBooking()` consolidation over deletion** — made dead code live instead of deleting or leaving it unused.
- **i18n API error architecture: client-side `code → i18n` mapping`**, not server-side translation — the server has no access to the user's selected language.
- **i18n plan split into 3 files** (Foundation/Client/Admin) — independently reviewable, stoppable checkpoints.
- **Admin dashboard IS in scope for i18n** (confirmed 2026-07-15) — will be translated as its own later checkpoint.
- **Client validators return i18n keys, not prose** — pure functions have no `t()` access; callers wrap `t(result.error, result.errorParams)`.
- **Date formatters kept 100% backward-compatible** in Phase 0 — actual per-language wiring deferred to (and completed in) the client plan.
- **Brand-name text-splitting rule for `BrandNameDisplay`** (user-confirmed): split on whitespace; 2+ words → all-but-last in normal/bold style, last word in the thin/opacity-70 style (matching the existing "Somique" + "beauty" visual pattern); 1 word → whole string in the bold style, no split.
- **`'Salon Booking'` (the Prisma schema default for `TenantConfig.brandName`) is the correct fallback everywhere in the branding-fixes bundle** — not `'Somique Beauty'` — since the explicit goal was removing the last hardcoded references to the app's original single-tenant brand.
- **GDPR CSV export localization reversed from "deliberately deferred" to "in scope"** mid-session — the user explicitly asked for full coverage when the tenant-branding-fixes bundle was scoped, overriding the i18n-client plan's earlier discretionary call to leave it Polish.
- **Tenant-branding-fixes bundle treated as its own LIGHT-mode task, run immediately, separate from and not blocking the pending `i18n-admin_plan.md`** — user's explicit call when the bugs were found mid-session via manual testing.
- **Minor reviewer-flagged issues and scope gaps closed directly by the orchestrator** (typo fixes, the `HomeClient.tsx` addendum) rather than looping back through a full re-planning cycle each time — judged as proportionate given they were small, mechanical, same-pattern fixes already proven elsewhere in the same review round.
