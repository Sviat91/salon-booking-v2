## Decisions Made

- **Portal, don't just `position: fixed`, for floating UI nested inside animated/overflow-clipped ancestors** — a bare `position: fixed` can still get hijacked by an ancestor's CSS transform (creates a new containing block) or clipped by `overflow: hidden`; `createPortal(..., document.body)` sidesteps both. Portaled interactive content must `stopPropagation()` on `mousedown` so it doesn't trigger an ancestor's "click outside to close" listener.
- **`GET /api/client/appointments?phone=` was deleted, not patched** — it was simultaneously dead code (zero callers) and a live PII leak; the roadmap's own security concern was moot once the dead-code angle was confirmed, since the legitimate feature is already served securely elsewhere (session auth).
- **Admin bootstrap consolidated to exactly one path**: `scripts/create-admin.ts`. Both prior hardcoded-credential paths (`create-superadmin.ts`, `prisma/seed.ts`) were deleted rather than patched — per explicit user instruction to remove all dead/dangerous defaults outright rather than softening them.
- **Working cadence for ROADMAP.md execution, now saved to memory**: one bounded unit at a time (a "unit" is judgment-based — Priority 1's three tightly-related IDOR fixes were correctly one batch; Priority 2's items are heterogeneous enough to each be their own unit), verify live after each (not just trust agent/reviewer claims — reviewer agents in this environment consistently lack Bash access), update `ROADMAP.md`, then stop for the user's own review and commit before continuing.
