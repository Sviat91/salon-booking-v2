## 🟡 Приоритет 3 — Не критично, но стоит сделать до продажи

- ~~Регистрация не ограничена по частоте — можно спамить аккаунтами.~~ — **сделано (2026-07-14).** `POST /api/auth/register` теперь rate-limited по IP (5 запросов / 15 минут) через уже существующий `rateLimit()` из `src/lib/cache.ts` — тот же паттерн, что у `forgot-password`/`reset-password`/GDPR-эндпоинтов. Проверка стоит первой строкой в `POST`, до парсинга тела запроса. План+ревью в `handoff/registration-rate-limit_plan.md`/`_feedback.md`.
  > **Найдена отдельная, более широкая проблема (не тронута в этом проходе):** `rateLimit()` в `src/lib/cache.ts` тихо "открывается" (разрешает всё), если Upstash Redis не настроен/недоступен — это касается уже всех 6 существующих rate-limited эндпоинтов, не только регистрации. Не критично, если Upstash всегда настроен в проде, но стоит закрыть отдельным заходом (in-memory fallback-счётчик, по аналогии с `cacheGet`/`cacheSet` в том же файле, которые такой fallback уже имеют).
- ~~Проверка телефона гостя при отмене/переносе — только по последним 9 цифрам (не по полному номеру).~~ — **сделано (2026-07-14).** Все 5 маршрутов (`cancel`, `update-time`, `update-procedure`, `bookings/[id]`, `bookings/all`) теперь сверяют владельца по полному нормализованному E.164-номеру через новый общий `phonesMatchE164()` (`src/lib/utils/phone-normalization.ts`), а не по последним 9 цифрам.
- ~~`app.db` и файлы загрузок закоммичены в git (хотя в `.gitignore` `*.db` есть).~~ — **сделано (2026-07-14, частично).** `app.db` и 21 файл `public/uploads/*` сняты с отслеживания (`git rm --cached`, файлы остались на диске); `.gitignore` дополнен `public/uploads/`. **Компромисс:** история git всё ещё содержит старые байты — полная чистка (`git filter-repo`/BFG + force-push) не делалась, это отдельная, более рискованная задача.
- ~~Нет security-заголовков (CSP, X-Frame-Options и т.д.).~~ — **сделано (2026-07-14, компромисс).** `next.config.mjs` → `headers()` задаёт CSP (`script-src`/`style-src` с `'unsafe-inline'`, allowlist для аналитики и Google-изображений, `frame-src`/`frame-ancestors 'self'`), `X-Frame-Options: SAMEORIGIN`, `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `Permissions-Policy`. **Компромисс:** CSP использует `'unsafe-inline'`, а не nonce-based — `layout.tsx` рендерит несколько inline-скриптов с динамическим на-запрос содержимым, полный переход на nonce отложен как отдельная, более рискованная задача.
- ~~Возможна гонка при двойном бронировании одного времени (низкая вероятность).~~ — **сделано (2026-07-14).** Проверка конфликта + запись обёрнуты в единый `prisma.$transaction` в `book`, `bookings/update-time`, `bookings/[id]` — без DB-уникальности (проверка идёт по пересекающемуся диапазону, а не по точному слоту, так что `@@unique` не закрыл бы дыру).
- ~~Захардкоженная услуга-заглушка "Консультация" на русском в универсальном приложении.~~ — **сделано (2026-07-14).** Заглушка теперь называется `"General Service"`.

Точечно перепроверено (2026-07-16): в `pl.json`/`en.json` нет посторонней кириллицы (кроме легитимного `"uk": "Українська"` — название языка в селекторе); оставшиеся кириллические строки в `src/` — это либо dev-комментарии на русском (не пользовательский текст, осознанно вне периметра аудита), либо словарь `procedure-translator.ts` (известная отдельная проблема, см.
