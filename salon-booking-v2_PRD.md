# 🚀 PRD: Полная переработка Salon Booking

<aside>
🔍 Документ составлен на основе анализа текущего репозитория (Next.js 14 App Router, Tailwind, интеграции в src/lib/google). Цель: превратить проект в автономную SaaS-платформу (White-label) с локальной БД и экосистемой Telegram-ботов.

</aside>

## 1️⃣ Отказ от Google API и переход на SQLite

- Стек: Prisma ORM + SQLite (идеально для изоляции клиентов, бесплатно, файл app.db лежит локально).
- Рефакторинг кода: Полное удаление папки `src/lib/google/` (sheets.ts, calendar.ts, drive.ts).
- Календарь и доступность: Переписываем `src/lib/availability.ts`. Теперь свободные слоты вычисляются не парсингом Google Calendar, а SQL-запросом к таблице `Appointments` с учетом таблицы `Schedules` (где заданы рабочие часы, выходные и перерывы мастера).

## 2️⃣ Админ-панель и Ролевая модель

- Стек: NextAuth.js (Auth.js) для секьюрной авторизации.
- Роль SUPERADMIN (Владелец): Доступ к роуту `/admin`. Видит всю статистику, может добавлять/удалять мастеров. При добавлении мастера система генерирует UID и пароль для входа.
- Роль MASTER (Сотрудник): Доступ к роуту `/admin/master`. Видит только свои записи, может проставлять себе выходные (если разрешено админом) и отменять записи.

## 3️⃣ Клиентский опыт (Регистрация и Букинг)

- Гостевой флоу: Сохраняем текущую возможность записаться без регистрации (максимальная конверсия).
- Личный кабинет клиента: Вход по номеру телефона/email. Роут `/profile`.
- Быстрая запись: В личном кабинете выводится история процедур с кнопкой «Повторить». В 1 клик подтягивается тот же мастер и услуга.

## 4️⃣ Telegram-бот для клиентов (Booking Bot)

- Архитектура: Бот работает на Telegraf.js. Может быть запущен как отдельный процесс или через Webhook прямо в Next.js API Routes.
- Синхронизация: Бот обращается к той же базе SQLite через Prisma. Никаких конфликтов расписания.
- Интерфейс: Реализация через Telegram WebApp (открывается мини-версия сайта прямо в ТГ) ИЛИ через классические Inline-кнопки (Выбор мастера -> Услуга -> Дата).

## 5️⃣ Telegram-бот для мастеров (Замена n8n)

- Отказ от n8n: Логика уведомлений переносится внутрь Next.js. При успешном создании/отмене записи в `src/app/api/book/route.ts`, сервер сам дергает Telegram API и шлет пуш.
- Функционал для мастера: Получение уведомлений о новых записях. Команды `/today` (расписание на день), `/cancel [id]` (отмена записи клиенту).
- Функционал для админа: Ежедневные отчеты (сколько записей, какая выручка).
